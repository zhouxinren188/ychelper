1. 快速打标店铺登录改用京东官方店铺资料接口读取真实店铺名称和登录账号，不再从页面文字、手填名称或登录名推测；接口未返回有效店名时会阻止保存错误资料并提示稍后重试。
2. 店铺 ID 与商家 ID（vendorId）改为独立保存。vendorId 通过免 h5st 的登录身份接口读取，不再把店铺链接中的数字误认为商家 ID；部分店铺两者恰好相同也不会再掩盖数据来源错误。
3. 快速打标向商家端发布任务时，优先使用 vendorId 与商家端 spShopNo 精确匹配目标店铺；商品导入继续传递该 vendorId，避免店铺改名或店铺 ID 与商家 ID 不一致时选错店铺。
4. 已保存的旧店铺账号无需重新添加：账号 Cookie 在线检测成功后会自动补齐 vendorId。店铺 Cookie 仍保存在原有稳定加密目录，升级不会清空账号、密码、Cookie、采集任务或业务配置。
5. 快速打标任务列表保留“批量打标”和“批量下标”。可勾选多个已完成的采集任务，逐店配置并创建任务；下标模式按实际步骤识别，支持“取消京配”以及“库存归零并停用”，不依赖快捷模式名称。
6. 批量打标与批量下标继续使用可靠的逐店发布队列。每家店铺独立选择快捷模式、目标店铺和仓库，单店失败不会中断其他店铺，成功与失败状态可分别追踪和重试。
7. 快捷模式管理支持编辑、重命名和拖动排序；编辑、删除按钮保持统一尺寸。重命名会同步更新店铺自动打标配置及已有任务中的模式引用，并完整保留采购数量和自动验收设置。
8. 物流服务定时开关继续固定当前登录账号事业部，每次执行前重新读取 CP 端物流服务、仓库及增值服务配置，只添加或删除“仓配一体服务 / 青龙”，其他物流服务和仓库配置保持不变。
9. 标准版、高级版及有效试用账号继续按现有权限使用快速打标和自动定时打标；快速打标店铺账号本地保存上限为 1000 家，多店铺采集、任务持久化及逐店发布流程保持不变。
10. 保留京配打标与取消请求的超时、退避重试、停止任务中断及商家端环境隔离修复，避免网络无响应导致任务永久卡住；进入商家端和进入 CP 端窗口继续默认最大化并复用当前账号会话。
11. 强化本地账号配置保护：临时读取、解密或解析失败时保留原文件并阻止空配置覆盖，启动时保存最近一次有效恢复快照；历史异常空配置会在迁移前自动恢复并保留回退文件。
12. WMS Cookie 继续独立保存在稳定的加密用户目录中，并在覆盖前保留恢复副本。登录校验失败只清空当前会话并打开登录页，只有用户明确删除 WMS 账号时才删除对应 Cookie 及恢复副本。
13. 本版本修改 Electron 主进程店铺身份识别逻辑，因此发布完整安装包、blockmap 和 latest.yml。appId、安装目录及用户数据目录保持不变；v1.0.83 与 v1.0.66 用户继续通过既有兼容桥接升级，其他受支持版本可直接升级到 v1.0.92。
