1. 新增店小二云仓订单执行能力：绑定设备在线且 WMS 登录有效时，可按店小二订单号执行首次打印、通道补打和快速发货，并向调用方返回明确的业务确认结果；云仓订单查询可省略订单号和年份，返回当前仓库、本年度全部待打印订单。
2. 云仓助手“打印出库”增加订单号输入以及“打印订单”“通道补打”“快速发货”入口，复用当前登录的 WMS 仓库和页面环境，不另外登录 WMS，避免同一账号被重复登录顶下线。
3. 打印和补打在执行前精确查询当前仓库订单，要求订单号唯一命中；页面、仓库、登录状态或业务结果无法确认时立即停止。写操作具备幂等、同订单互斥、有效期和写后状态确认，未知结果不会自动重复执行。
4. WMS 登录成功后会在现有打印出库区域预加载订单处理运行环境；用户正常查看 WMS 时仍可通过顶部“出库管理”恢复常用菜单展示，不再模拟点击侧栏业务按钮。
5. 异常订单处理页新增“进入商家端”和“进入CP端”按钮；商家端直接显示登录后保留的 `o.jdl.com` 后台窗口，CP 端以同一账号 Session 打开 `cp.jdl.com`，不创建第二套登录环境。关闭商家端窗口时仅隐藏，以继续保障店铺查询和打标运行环境。
6. 完善店小二云仓指令协议、服务器设备能力声明以及打印、补打、发货的本地和 HTTP 往返测试；同时修复新 Windows 电脑上原生店铺查询传输模块自检连接被提前关闭的问题。
7. 修复完整安装包下载并校验完成后，云仓助手退出但安装器没有启动、再次打开仍停留在旧版本并重复升级的问题。安装器现在会在当前程序仍能反馈结果时创建，遇到 Windows 临时文件占用会自动重试，确认安装进程成功启动后才退出。
8. 继续保留安装包等待旧程序退出的保护，并保持原有 appId、安装目录和用户数据目录不变；升级不会主动清除 WMS Cookie、账号或业务配置。
9. 本版本为完整安装包版本，提供安装包、blockmap 和 latest.yml。v1.0.83 用户会先获得 v1.0.83.1 升级桥接再自动安装 v1.0.85；其他受支持版本继续按完整包或既有 v1.0.66 兼容链升级到 v1.0.85。
