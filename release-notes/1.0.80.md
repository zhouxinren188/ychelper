1. 新增“其他 → 机器码”页面：机器码按“当前设备 × 云仓助手账号”稳定生成并持久保存，可复制用于店小二账号绑定和中央任务路由；不同设备或不同云仓助手账号使用不同机器码。
2. 新增受控的云仓订单执行链路：桌面端只接收与本机机器码完全匹配的固定白名单命令，当前支持异常订单查询与处理；保留幂等、订单锁、执行前复验、执行后复验、审计和待人工复核，禁止任意代码、脚本、模块路径或 URL 执行。
3. 加固异常订单查询结果：明确区分“商家登录已失效”“查询到异常订单”“暂无异常订单”和普通失败；异常原因与真实处理方案经过脱敏后返回，两处固定来源只有都正常返回 0 条时才判定无异常。
4. 优化异常查询超时：两个来源并发、各自独立执行 1 秒超时与最多 3 次超时重试；Cookie 失效、正常 0 条和普通接口错误不重试，避免任务长期卡在执行中或把超时误报为无异常。
5. 保护事业部在线设备：达到版本在线数量上限时拒绝新设备进入，不再顶掉正在操作的设备；同一设备重启可续接自己的名额，正常退出主动释放，异常退出由心跳租约回收。
6. 在线名额不足时提供升级通道：显示当前在线数与版本上限，自动推荐第一个能够增加名额的更高版本；用户也可让其他设备退出后重新检测，高级版已满时明确提示先释放设备。
7. 快速打标新增商品列表右键管理：SPU 可整组勾选、取消勾选或删除当前商品全部 SKU，SKU 行只操作当前 SKU；删除仅影响本次本地结果，不会向京东发出删除或上下架请求。
8. 快速打标查询按钮组改为居中；右键操作后保留其他商品的勾选与展开状态，查询进行中自动禁用右键，避免异步结果替换冲突。
9. 保留快速打标稳定查询节奏：按“每页 SPU → 本页逐个 SKU → 下一页”串行执行，响应完成后保持请求间隔；继续先做价格筛选，再按每个 SPU 执行全部、第一个、最后一个、最低价、最高价、前 N 个或随机 N 个筛选。
10. 保留店铺账号与 Cookie 隔离、重复账号覆盖、凭据安全保存、自动填写、桌面 TXT 导出及发送到打标/下标；查询失败会清空旧结果，避免误导出上一次数据。
11. 保留 WMS 多仓库名称和编号识别、有效 Cookie 恢复、待验收单据查询及网络异常不误删 Cookie；保留商家端验证码页面显示和登录成功后隐藏工作台。
12. 本版本为完整安装包版本，提供安装包、blockmap 和 latest.yml。v1.0.66 用户继续通过 v1.0.66.3 与 v1.0.68 兼容桥接升级；v1.0.67 及以后清单内受支持版本可直接升级到本版本，账号、Cookie 与业务配置继续保存在稳定用户目录。
