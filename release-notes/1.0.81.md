1. 新增云仓订单查询能力：店小二可按绑定机器码、订单号和年份向当前在线的云仓助手发起只读查询；客户端使用本机有效 WMS 会话核对订单是否存在，命中时安全返回对应运单号，未登录 WMS 时明确提示重新登录。
2. 优化机器码页面连接状态：页面打开或重新进入时会及时刷新云仓助手服务连接状态，避免服务已经在线但界面长期停留在“连接中”。
3. 完善在线名额升级通道：达到当前版本在线设备上限时仍不会顶掉正在操作的设备，可直接选择更高版本增加名额，也可让其他设备退出后重新检测。
4. 升级版本改为只补剩余有效期差价：服务器严格沿用当前真实月度、季度或年度计费标准，按剩余整天计算目标版本价值与当前版本抵扣，支付成功后原订阅到期时间保持不变。
5. 优化升级界面：升级时不再选择月度、季度或年度；选择更高版本后自动显示剩余天数、抵扣和实付金额，报价完成后一次点击即可创建支付订单。
6. 修复历史订阅周期显示错误：本地缓存缺少周期时不再擅自回退为年度，以服务器返回的真实订阅周期为准；登录检查与心跳会持续同步周期信息。
7. 合并并精简在线名额与升级计费说明，避免重复提示；报价失败时提供明确的重新计算入口，不会一直停留在计算状态。
8. 本版本为完整安装包版本，提供安装包、blockmap 和 latest.yml。v1.0.66 用户继续通过 v1.0.66.3 与 v1.0.68 兼容桥接升级；v1.0.67 及以后清单内受支持版本可直接升级到本版本，账号、Cookie 与业务配置继续保存在稳定用户目录。
